## Zasady na zajęciach

1. Każdy projekt -> osobne repozytorium na Twoim GitHubie, publiczne.
2. Koniec zajęć -> `commit` + `push`. Nie ma pusha, nie ma dowodu.
3. Każde repo ma `README.md` i `.gitignore`.
4. LLM wolno używać. Ale na następnych zajęciach pytam o kod. Wiesz, co robi każda linia - OK. Nie wiesz - do poprawy.
5. Komputery w pracowni są wspólne: na koniec zajęć **usuwasz poświadczenia GitHub** (instrukcja w materiale 01, rozdział 11).
